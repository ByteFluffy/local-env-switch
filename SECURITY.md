# Security Policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting flow for this repository. Open the
repository's **Security** tab, choose **Advisories**, and select **Report a
vulnerability**.

Do not include real secrets in reports, logs, fixtures, screenshots, or public
issues. Include the affected version, a minimal reproduction with synthetic
values, the expected security boundary, and the observed behavior.

Public disclosure should wait until a fix and coordinated release are ready.
